# Guidelines

Learning project: local ML pipeline predicting partner status from public survey data (NLSY97, NHANES, HCMST). Plans and decisions: `agent-docs/` (link to ~/agent-docs/girlfriend-predictor).

- Keep code simple and easy to read. No premature abstraction.
- Comments and docstrings: concise, high-value only. Explain *why*, not *what*.
- Prefer plain scripts in `src/`; notebooks only for exploration.
- Never modify files in `data/raw/`.
